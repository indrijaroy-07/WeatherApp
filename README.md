# Weather App
Separate application for the minor project.

## Requirements covered
- Search weather by city
- Temperature and weather conditions
- Humidity and wind speed
- Graceful API error handling
- Responsive UI
- ES6 arrow functions, destructuring, template literals and modules
- DOM manipulation, event handling and form processing
- Promises, async/await, Fetch API and error handling
- JSON/API response rendering

## Run
Open this folder in VS Code and use Live Server on `index.html`.
No API key is required because the app uses Open-Meteo public APIs.
